# open-jev：H800 实际训练报告

2026-09-22，通过 `hsh_fj2` 在 NVIDIA H800 上用最终提交源码从随机初始化实际训练。

## 结果

| 对照 | 独立测试准确率 |
|---|---:|
| 未训练模型 | 41.67% |
| 按训练集多数类别作答 | 52.22% |
| 训练后模型 | 100.00% |

Choice、Noul、Score 各 60 条测试样本，三项准确率均为 100%。训练交叉熵从第 1 轮的 0.877167 降至第 40 轮的 0.001251；验证交叉熵从 0.843251 降至 0.001176。测试 NLL 为 0.001315，Brier 为 0.00000673，ECE 为 0.001313，Score 期望等级 MAE 为 0.003757（0–3 分）。

![训练曲线](../../examples/synthetic-v2/curves.png)

## 数据和模型

- 600 个不同状态，每个状态生成 Choice、Noul、Score 三个问题，共 1,800 条。
- 训练 1,260 条；验证、保留校准、测试各 180 条。按 case 分组切分，跨集合没有相同 case 或完全相同状态。
- 风险和延迟决定标签，其余字段为干扰特征。标签来自公开规则，没有调用外部模型生成答案。
- 共有 972 种状态组合，但只有 9 种风险/延迟组合。这是简单、无噪声的同分布组合测试；规则代码也可以达到 100%。
- 模型是词嵌入均值池化 + 动态候选 MLP，12,225 参数，从零训练；没有使用预训练 LLM。
- AdamW，学习率 0.003，batch size 32，hidden size 64，seed 7，40 epoch。
- 按验证集 NLL 选模型，本次选中第 40 轮；校准集未使用，没有实施温度校准。

## 执行证据

- 实际设备：`cuda` / `NVIDIA H800`。
- 训练循环耗时：9.57 秒（不含环境准备与传输）。
- PyTorch 峰值 tensor allocation：72.35 MiB。此值不含 CUDA context 或其他进程显存。
- GPU checkpoint 重载最大概率差：0.0。
- 本地 CPU 重载验证 180 条预测结论全部一致，最大概率差约 1.37e-8。
- 数据集指纹：`ae9204577492751f2f04c2c28472ca656c5fabcc929cceb39b041b82b3b02fab`。
- 权重、数据、逐轮日志、逐条预测、版本、SHA-256 校验均保存在[完整实验目录](../../examples/synthetic-v2/README.md)。

本次测试证明数据处理、梯度训练、验证选模、评测和权重重载可以完成闭环。它不能证明真实业务准确率、多语言能力、未知任务泛化，也不能用于推断 TypeSafe Jev 的能力或架构。

## 复现

```bash
pip install -e .
open-jev train-synthetic --output artifacts/my-run --groups 600 --epochs 40 --batch-size 32 --seed 7 --device cuda
```

没有 CUDA 时用 `--device cpu`。每次指定新的输出目录。

## 本次修复

Noul 的 true/false 候选原来都可能编码成 UNK，使两项得分无法区分，现已修复并加入学习能力回归测试。同时补齐了模型初始化种子、CUDA tensor 搬运、验证集选模、稳定 Choice 输出 key、自描述 checkpoint 和真实 CLI 入口。
